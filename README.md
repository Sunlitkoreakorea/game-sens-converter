# 게임별 마우스 감도 변환기

발로란트, CS2/CS:GO, 오버워치 2, 배틀그라운드, 에이펙스, 포트나이트, 레인보우 식스 시즈, 콜 오브 듀티, 데스티니 2, 러스트 사이의 마우스 감도를 **cm/360°** 기준으로 변환하는 웹 도구입니다.

- 사이트: https://sunlitkoreakorea.github.io/game-sens-converter/
- 입력 DPI와 변환 후 DPI를 각각 직접 입력할 수 있습니다.
- 게임 감도 대신 직접 잰 cm/360을 입력할 수도 있습니다.
- 현재 설정을 담은 공유 링크를 복사할 수 있습니다 (`?g=게임&s=감도&d=DPI&t=변환후DPI`, 또는 `?c=cm&d=DPI`).
- 게임별 전용 페이지(`/valorant/`, `/cs2/`, `/pubg/` …)와 cm/360별 감도 대응표를 제공합니다.

## 구조

```
index.html, <게임>/index.html   생성된 페이지 (직접 수정하지 말 것)
app.js, style.css               공통 스크립트/스타일
og.png                          링크 미리보기 이미지 (1200×630)
sitemap.xml                     생성됨
_build/games.json               게임 데이터 (yaw, 표시 자릿수, 대응표용 값)
_build/template.html            페이지 템플릿
_build/build.mjs                생성 스크립트
```

게임을 추가하거나 값을 고친 뒤에는 다시 생성합니다.

```bash
node _build/build.mjs
```

## 계산식

```
cm/360    = 360 × 2.54 ÷ (감도 × yaw × DPI)
변환 감도 = 914.4 ÷ (cm/360 × yaw × DPI)
```

`yaw`는 감도 1.0에서 마우스 1카운트당 회전 각도(°)입니다.

| 게임 | yaw |
| --- | --- |
| 발로란트 | 0.07 |
| CS2 / CS:GO, 에이펙스 레전드 | 0.022 |
| 오버워치 2, CoD(MW3·Warzone·BO6), 데스티니 2 | 0.0066 |
| 포트나이트 (X/Y 감도 %) | 0.005555 |
| 레인보우 식스 시즈 | 0.00572957795 |
| 러스트 | 0.1125 |

공개된 감도 변환기 자료 여러 곳을 교차 확인한 값입니다. 출처끼리 값이 달랐던 게임(Marvel Rivals, Deadlock 등)은 포함하지 않았습니다.

### 배틀그라운드 (근사)

배그 일반 감도는 선형이 아니라 **지수 곡선**입니다. 슬라이더 15칸마다 회전 속도가 2배가 됩니다.

```
°/카운트 = 0.042 × 2^((슬라이더 − 50) ÷ 15)
```

- 곡선의 모양(15칸 = 2배)은 한국 커뮤니티 자료 여러 곳에서 일치합니다. 같은 eDPI 예시 `400 DPI·50 = 800 DPI·35 = 1600 DPI·20`도 이 곡선과 맞습니다.
- 기준점(슬라이더 50 ≈ 0.042°/카운트, 발로란트 0.6 상당)은 제보된 대응값 1건(발로란트 0.19 @ 1600 DPI ≈ 배그 25)으로 맞춘 값이며 독립적으로 검증하지 못했습니다.
- 슬라이더는 정수라서 한 칸 차이가 약 4.7%입니다. 조준경(ADS)·수직 감도 배율은 다루지 않습니다.
- 이런 이유로 정적 대응표에서는 배그를 뺐습니다. 정확히 맞추려면 직접 360°를 돌려 cm를 재고 "cm/360 직접 입력"을 사용하세요.
